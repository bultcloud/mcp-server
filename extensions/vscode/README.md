# Bult.ai MCP Server for VS Code

This extension registers the official Bult.ai MCP Server with VS Code.

Bult.ai is a DevOps platform and cloud hosting Platform-as-a-Service for
deploying apps, GitHub repositories, Docker images, databases, and services.
With this extension, VS Code agent mode can use Bult MCP tools to manage
projects, services, routes, volumes, templates, deployments, logs, and builds.

## Requirements

- Node.js 18 or newer
- A Bult.ai API token

## Setup

1. Install the extension.
2. Run `Bult.ai MCP: Set API Token` from the Command Palette.
3. Open the MCP server picker in VS Code and start `Bult.ai MCP Server`.

The default API URL is `https://app.bult.ai`. You can change it in VS Code
settings under `Bult MCP: API URL`.
