description: Show Bult project status, services, routes, volumes, and deployment health.
---

Show the current Bult project status.

Use structured Bult MCP tools when available. If using the CLI, prefer:

```bash
bult status --json
```

Summarize project name, project ID, services, service statuses, public routes,
volumes, latest deployment state, and errors.
