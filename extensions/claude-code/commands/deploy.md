Use Bult to deploy the current project.

Steps:

1. Identify the active or linked Bult project.
2. If no project is selected, list projects and ask the user which one to use.
3. Deploy the project.
4. Check deployment status.
5. If a service fails, inspect recent logs and summarize the failure.
